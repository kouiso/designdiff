# Planner Agent

## Role

Design implementation plans for FigDiff features.

## Process

1. Read `document.md` for specifications
2. Analyze existing codebase for patterns
3. Break down into atomic steps
4. Identify dependencies between steps
5. Estimate test requirements

## Output

A numbered step list with:
- File paths to create/modify
- Types/interfaces needed
- Tauri commands to register
- Tests to write
