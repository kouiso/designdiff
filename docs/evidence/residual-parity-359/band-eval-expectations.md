# band-eval v2 — 期待判定の独立登録（実装を観測する前に確定）

前回 (band-eval.mjs) の誤り: 期待値を「1/8帯の平均が2以上ならfire」と、
検証対象である帯アルゴリズム自身の式で定義していた。自己採点であり、
40×40 の訂正もその式への追随だった。以下は実装式を一切使わず、
「その差が許容されるレンダラ差か、実際の設計差か」だけから決めた期待値。

## 期待を決める独立根拠（実装非依存）

- 原画像: 120×120 全面 #FFFFFF（白）。変異で一部領域の色だけを変える。
- 変異色: #EFF8F2（ミント、9949-23513 の実デザインのグラデ下端色）と
  #F7F7F7（実装スクショの無彩色）の実ペア。CIEDE2000 = 5.2（実測、
  9949-23513 の実画像から計算済み。JND≈1.0 の5倍強で、均一領域では
  誰でも見える色差）。
- レンダラ差になり得るもの: アンチエイリアス縁・JPEG/写真ノイズ・
  サブピクセル描画差。これらは (a) 画素あたり ΔE が小さい (≲1.5)、
  (b) 零平均、または (c) エッジ局在、のいずれか。フラットな面が
  まるごと ΔE5.2 ずれることはレンダラでは起きない。
- よって:
  - ΔE 5.2 の均一な色ずれが 3 画素幅以上の帯/ブロック（≥360px）に
    及ぶものは *実際の設計差* → 期待 FAIL。形状・位置・帯境界との
    関係で期待を変えない（人間の目に帯分割は存在しない）。
  - 画素あたり ΔE ≤ 1.5 程度の全面一様ずれ、零平均ディザ/ノイズ、
    なめらかな階調差は *許容されるレンダラ/符号化差* → 期待 PASS。

## ケース一覧（全ケース 120×120、「無関係diff なし/あり」の2変種）

無関係diff = 1px の濃灰線 (#333) が 2px 平行移動（pixelmatch が確実に
拾い、rasterization_tolerance で説明される想定の足場）。「なし」変種は
変異のみ。compareImages の入口から両変種の最終判定を別々に記録する。

### FAIL 期待（実際の設計差: ΔE 5.2 の均一ずれ）
1. band-top: y0-15 全幅
2. band-middle: y52-67 全幅
3. band-bottom: y105-120 全幅（9949-23513 と同形）
4. straddle: y100-115 全幅（8分割境界 y105 をまたぐ）
5. straddle-thin: y101-109 全幅（高さ8、境界をまたぐ）
6. narrow-7: y106-113 全幅（高さ7）
7. narrow-3: y106-109 全幅（高さ3。細いが全幅×ΔE5.2 は明瞭に見える）
8. wide-30: y90-120 全幅
9. block-40x40: 中央 (40,40)-(80,80) の局所色ブロック。
   ※ pixelmatch 閾値 (0.1 YIQ) 未満なら cluster 採点に乗らないが、
   「cluster の責務」で quiet 合格にはしない。1600px が ΔE5.2 で
   違う実欠陥なので期待は FAIL。
10. vstripe-8: x60-68 の縦帯・全高（8×120=960px、ΔE5.2）

### PASS 期待（許容されるレンダラ/符号化差）
11. uniform-1.5: 全面 #FAFAFA 化（ΔE≈1.5、知覚閾 2 未満）
12. gradient-ramp: 白→ミントのなめらかな縦グラデ同士のわずかな傾き差
    （画素あたり ΔE ≤ 0.3）
13. aa-dither: ±1 の市松ディザ（ΔE≈0.4、零平均）
14. photo-noise: ±3 の決定論的ノイズ（零平均、写真/JPEG 相当）

### 足場の健全性
15. sanity-displacement-only: 無関係diff のみ・色変異なし → PASS 期待
    （これが FAIL なら足場が壊れており全結果を無効化して作り直す）
16. sanity-identical: 完全同一画像 → PASS 期待

## 集計ルール
- 見逃し = FAIL 期待で PASS/UNCERTAIN。誤検出 = PASS 期待で FAIL。
  未判定 (UNCERTAIN/inconclusive) は見逃しとも誤検出とも別に数える。
- 実装の帯式・閾値は期待の定義に一切使わない。観測後に期待を変えない。
