# #427 自己レビューと敵対レビュー (2026-11-01)

## 最終判断

既存の全画面差分率と、今回試した独立診断では、保存済みpass/fail群は分離しない。再現可能な測定と入力防御を改善したが、#243の修正・#427の受入完了には至っていない。未検証の撮影条件を埋めたり、満点と認定したりしない。

correct群はpass最大8.8825%、fail最小4.1004%、gap=-4.7821pp。drift/linewidthを含む期待判定別の全variantでは、同寸法pass12件、fail18件で、pass最大8.8825%、fail最小2.1502%、gap=-6.7323pp。寸法不一致のfail3件は数値率から除外し、nullを維持した。これらはこの標本の単調な高率→failの閾値で分離しないことを示す。他の画像指標がすべて不可能だという主張ではない。

## 反証と修正の往復

1. 自己レビューと独立レビュアー2名が、原コード・原PNGハッシュ・測定JSON・256binの集計・保存ログを別々に照合した。数値の破損は見つからなかったが、入力防御・coverage・再現手順・通常test接続の欠陥が見つかった。
2. 入力防御担当と証跡担当を分けて修正した。その後、他方の変更を読んで再レビューし、監査の必須source hashから新しいfixture moduleが漏れている点と、従来型検査がstrictでなかった点を追加指摘した。両方を修正した。
3. 科学的見解も反証した。「輪郭ならAA」「56pxなら同じ撮影条件」「選んだ指標が重なるのであらゆる独立指標が不可能」はいずれも成立しないと合意した。標本内の指標の重なり、観測された幾何差、原因の未確定を分けて報告する。

4. 再現手順の引数について一方が反対したが、現行ソースのargparse実装と引数付き4テストの実行結果で解消し、旧版の読みに基づく指摘は撤回された。相互の要約をそのまま採用せず、実コードと実行で判断した。

最終の合意は、修正した測定系の確認範囲と未達の線引きに限定する。レビュアーの同意を独立な意味的正解の代用にしない。

## 受入のために不足するもの

pair22等の部分的な約56px変位が撮影条件差なのか実レイアウト差なのかを裏付ける、現在PNGと紐づいた生成版・実行ログ・viewport/DPR/inset/keyboard条件が必要。履歴SHA不一致のため、別時点のhelper既定値を代用できない。同条件の新しい正本、または独立根拠付きの許容対応領域がない状態で、閾値を調整して受入完了にはしない。

現行の測定に対するローカル検証は validation.json、review/ の各ログ、reproduction.md を参照。今回のローカル修正は旧Libraryアーカイブへ自動反映されない。

最終実行: Node26.12.1の12テスト、Biome、ESLint、strict checkJs、派生PNG15件、測定/プローブのbyte一致、Pillow独立監査、Python4テスト/9破損検査が全てexit0。関連範囲のローカル検証の結果であり、製品全体CIや受入の成功とは区別する。審査待ち操作は今回発生しておらず、利用可能なdots催促用経路も見つからなかった。
